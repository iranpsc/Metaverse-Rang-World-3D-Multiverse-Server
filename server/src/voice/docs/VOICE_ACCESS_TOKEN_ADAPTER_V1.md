# سازگارکننده توکن دسترسی ارتباط صوتی

## اتصال به سامانه فعلی

ارتباط صوتی از همان نمونه `tokenService` موجود در پروژه استفاده می‌کند.

مسیر نمونه فعلی:

`src/core/auth/auth.instance.js`

تابع مورد استفاده:

`tokenService.verifyAccessToken`

این تابع توکن را با کلید عمومی، الگوریتم، صادرکننده و مخاطب تنظیم‌شده پروژه بررسی می‌کند.

## نتیجه بررسی

سازگارکننده یکی از نتیجه‌های زیر را برمی‌گرداند:

| نتیجه | کد |
|---|---:|
| توکن معتبر و دارای شناسه کاربر | 0 |
| توکن ارسال نشده | 2 |
| توکن نامعتبر | 3 |
| توکن منقضی | 4 |
| شناسه کاربر در توکن وجود ندارد | 5 |

## شناسه کاربر

شناسه کاربر فقط از بخش `sub` توکن تأییدشده خوانده می‌شود.

توکن خام و شناسه ادعایی کاربر داخل نتیجه نگهداری نمی‌شوند.

## محدوده این مرحله

این مرحله اعتبار توکن و شناسه کاربر را بررسی می‌کند.

بررسی عضویت روم، مالکیت آواتار، اتصال ریل‌تایم و اتصال سرور اختصاصی در سازگارکننده‌های بعدی به همین نتیجه اضافه می‌شوند.

## توضیح این فایل

این فایل نحوه اتصال سامانه ارتباط صوتی به سرویس توکن فعلی پروژه و نتیجه‌های قابل تولید هنگام بررسی توکن دسترسی را ثبت می‌کند.
