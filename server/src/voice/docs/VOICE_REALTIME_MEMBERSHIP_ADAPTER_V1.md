# سازگارکننده عضویت ریل‌تایم ارتباط صوتی

## منبع اتصال‌ها

اتصال‌های فعال کاربر از رجیستری فعلی ریل‌تایم خوانده می‌شوند:

`registry.getAll(userId)`

این تابع اتصال‌های بسته‌شده را نیز هنگام خواندن پاک می‌کند.

## بررسی احراز هویت

اتصال فقط زمانی معتبر است که:

- کاربر ثبت‌شده روی زمینه اتصال با شناسه کاربر تأییدشده برابر باشد.
- وضعیت زمینه اتصال برابر حالت احراز‌شده باشد.
- اتصال هنوز باز باشد.

## بررسی عضویت روم

عضویت با تابع فعلی مدیر روم بررسی می‌شود:

`rooms.hasConnection(roomId, connection)`

بنابراین فقط وجود یک کاربر با همان شناسه در روم کافی نیست و همان اتصال زنده باید عضو روم باشد.

## چند اتصال برای یک کاربر

رجیستری فعلی می‌تواند چند اتصال را برای یک کاربر نگه دارد.

سازگارکننده همه اتصال‌های فعال و احراز‌شده را بررسی می‌کند و نخستین اتصالی را برمی‌گرداند که واقعاً عضو روم درخواستی باشد.

## نتیجه‌ها

| وضعیت | نتیجه |
|---|---|
| ورودی ناقص | داده نامعتبر |
| اتصال فعال وجود ندارد | ریل‌تایم آماده نیست |
| اتصال وجود دارد ولی احراز نشده | ریل‌تایم آماده نیست |
| اتصال احراز شده ولی عضو روم نیست | کاربر عضو روم نیست |
| اتصال احراز شده و عضو روم است | بررسی موفق |

## امنیت

شناسه کاربر این مرحله از نتیجه تأییدشده توکن دریافت می‌شود.

شناسه روم فقط زمانی پذیرفته می‌شود که مدیر روم فعلی پروژه عضویت همان اتصال را تأیید کند.

## توضیح این فایل

این فایل نحوه بررسی اتصال ریل‌تایم و عضویت واقعی همان اتصال در روم مورد درخواست ارتباط صوتی را ثبت می‌کند.
