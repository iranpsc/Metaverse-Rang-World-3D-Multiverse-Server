# هسته اتصال صوتی نسخه یک

## وظیفه

هسته اتصال صوتی اطلاعات هر اتصال احراز‌شده را در حافظه نگه می‌دارد.

هر اتصال شامل این اطلاعات است:

- شناسه اتصال
- شناسه کاربر
- شناسه آواتار
- شناسه روم
- نوع سکوی کلاینت
- شناسه نمونه کلاینت
- نام راه انتقال
- شناسه اتصال راه انتقال
- آخرین شماره دریافت‌شده
- آخرین شماره منتشرشده
- زمان‌های ایجاد، فعال‌شدن، تعلیق، ادامه و بسته‌شدن

## وضعیت‌های اتصال

| مقدار | وضعیت |
|---:|---|
| 1 | احراز‌شده |
| 2 | فعال |
| 3 | معلق |
| 4 | در حال بسته‌شدن |
| 5 | بسته‌شده |

## ثبت اتصال

شناسه اتصال از اتصال تأییدشده همان بازیکن در سرور اختصاصی گرفته می‌شود.

برای هر شناسه نمونه کلاینت فقط یک اتصال ثبت می‌شود.

برای هر کاربر و آواتار فقط یک اتصال صوتی ثبت می‌شود تا یک جریان مرجع صوت برای هر آواتار وجود داشته باشد.

## تعلیق و ادامه

هنگام قطع موقت، همان اتصال به حالت تعلیق می‌رود.

پس از بازیابی موفق، همان اتصال با شناسه قبلی و راه انتقال جدید دوباره فعال می‌شود.

## حذف اتصال

هنگام خروج رسمی یا پایان مهلت بازیابی:

1. اتصال بسته می‌شود.
2. علت بسته‌شدن ثبت می‌شود.
3. اتصال از فهرست شناسه اتصال حذف می‌شود.
4. اتصال از فهرست شناسه نمونه کلاینت حذف می‌شود.
5. اتصال از فهرست کاربر و آواتار حذف می‌شود.

## توضیح این فایل

این فایل ساختار و رفتار هسته نگهداری اتصال‌های صوتی را به‌صورت مکتوب ثبت می‌کند.
