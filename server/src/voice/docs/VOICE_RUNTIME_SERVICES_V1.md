# سرویس‌های زمان اجرای ارتباط صوتی

## نمونه‌های زنده

سیستم صوتی از همان نمونه‌های زنده سرور استفاده می‌کند:

- رجیستری ریل‌تایم
- مدیر روم ریل‌تایم
- ثبت‌کننده نشست‌های سرور اختصاصی
- رجیستری اتصال صوتی

## ترتیب بررسی و ثبت

هنگام درخواست اتصال صوتی:

1. توکن بررسی می‌شود.
2. شناسه کاربر از توکن خوانده می‌شود.
3. حضور کاربر در روم ریل‌تایم بررسی می‌شود.
4. همان کاربر داخل نشست سرور اختصاصی همان روم پیدا می‌شود.
5. شناسه اتصال بازیکن از سرور اختصاصی خوانده می‌شود.
6. اتصال داخل رجیستری صوتی ثبت می‌شود.
7. اتصال وارد وضعیت فعال می‌شود.

## درخواست تکراری

اگر همان درخواست با همان شناسه‌ها دوباره ارسال شود، اتصال دوم ساخته نمی‌شود.

همان اتصال فعال قبلی برگردانده می‌شود.

## شناسه اتصال

شناسه اتصال صوتی از `connectionId` بازیکن داخل سرور اختصاصی گرفته می‌شود.

شناسه تصادفی جدید ساخته نمی‌شود.

## توضیح این فایل

این فایل مسیر کامل آماده‌سازی، ثبت و فعال‌سازی اتصال صوتی را توضیح می‌دهد.
