# قفل قرارداد نسخه یک ارتباط صوتی

## محدوده قرارداد

نسخه یک شامل این بخش‌ها است:

1. پوشش دودویی مشترک
2. شماره پیام‌ها و پرچم‌ها
3. درخواست و نتیجه احراز هویت
4. نشست‌های فاصله‌ای
5. بازیابی اتصال
6. تعلیق و پاک‌سازی نشست‌ها

## پوشش دودویی

- شناسه آغاز بسته: `MVVC`
- نسخه قرارداد: `1`
- اندازه سربرگ ثابت: `60` بایت
- ترتیب بایت‌ها: بزرگ به کوچک
- داده صوتی: باینری فشرده‌شده با اوپوس

همین پوشش در ارتباط وب‌سوکت امن و جی‌آرپی‌سی استفاده می‌شود.

## احراز هویت

- شناسه کاربر از بخش `sub` توکن تأییدشده خوانده می‌شود.
- شناسه کاربر اعلام‌شده توسط کلاینت پذیرفته نمی‌شود.
- روم، آواتار، اتصال ریل‌تایم و اتصال سرور اختصاصی بررسی می‌شوند.

## نشست فاصله‌ای

- هر نشست یک ارتباط مستقیم میان دو آواتار است.
- هر آواتار می‌تواند عضو چند نشست باشد.
- ارتباط صوتی انتقالی نیست.
- فاصله ورود کمتر یا مساوی ۳ متر است.
- فاصله خروج بیشتر یا مساوی ۳.۵ متر است.
- شناسه نشست را سرور ایجاد می‌کند.

## بازیابی اتصال

- نخستین تلاش بدون تأخیر است.
- مهلت کلاینت ۱۸۰ ثانیه است.
- نگهداری سرور ۲۱۰ ثانیه است.
- هنگام قطع موقت، ارسال صدا معلق می‌شود.
- پس از پایان نگهداری، اتصال و نشست‌ها پاک می‌شوند.

## مسیر موقت صحنه‌ها

جداسازی ورود عادی و ورود صوتی فقط برای محافظت از صحنه‌های سه‌بعدی فعلی در زمان توسعه است.

این جداسازی قانون دائمی معماری نیست.

هدف نهایی، فعال بودن ارتباط صوتی در صحنه‌های اصلی سه‌بعدی است.

## نتیجه فاز

پس از موفقیت همه آزمون‌های `V1.1` تا `V1.7`، قرارداد نسخه یک برای ورود به فاز `V2` آماده است.

## توضیح این فایل

این فایل تصمیم‌ها و قراردادهای نهایی فاز یک ارتباط صوتی را برای شروع ساخت هسته و راه‌های انتقال صوت ثبت می‌کند.
