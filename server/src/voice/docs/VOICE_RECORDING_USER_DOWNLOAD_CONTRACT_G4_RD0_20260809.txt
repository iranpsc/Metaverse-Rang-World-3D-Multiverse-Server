CONTRACT_SUMMARY:
- هر Voice Session یک فایل Mix کامل نهایی دارد.
- فایل اصلی ذخیره‌سازی سرور: session.ogg
- فایل متادیتای سرور: session.json
- فایل‌های partial فقط موقت هستند و هرگز برای کاربر قابل دانلود نیستند.
- هر کاربر فقط بخشی از Session را می‌تواند دانلود یا پخش کند که در آن حضور داشته است.
- تشخیص بخش مجاز دانلود باید از روی intervals داخل session.json انجام شود.
- خروجی دانلود کاربر باید یک فایل OGG واحد باشد، نه چند فایل تکه‌تکه.
- اگر کاربر در کل Session حضور داشته باشد، همان session.ogg قابل تحویل است.
- اگر کاربر فقط بخشی از Session حضور داشته باشد، سرور باید فایل مجاز را با Clip/Trim بسازد.
- اگر یک Session بسته و Burn شد و بعد Session جدید ساخته شد، فایل ضبط جدید و sessionId جدید دارد.
- چند Session مستقل نباید در یک فایل دانلودی ادغام شوند.
- فایل‌های ضبط‌شده نباید Public یا مستقیم از Nginx ارائه شوند.
- دانلود باید فقط از مسیر احراز هویت‌شده HTTP انجام شود.
- userId باید از Token معتبر گرفته شود.
- userId باید در همان session.json و intervals مجاز وجود داشته باشد.
- non-member باید 403 بگیرد.
- فایل آماده‌نشده یا partial باید 404 بگیرد.

REQUIRED_ENDPOINTS:
1) GET /voice/recordings
   - لیست ضبط‌های آماده و مجاز همان user
2) GET /voice/recordings/{sessionId}/download
   - دانلود فایل OGG واحد مجاز همان user
