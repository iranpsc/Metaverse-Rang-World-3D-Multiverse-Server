# بررسی حضور کاربر در سرور اختصاصی

## کار اصلی

هنگام ارسال صوت، شناسه کاربر و شناسه روم از قبل مشخص هستند.

سازگارکننده فقط این مراحل را انجام می‌دهد:

1. نشست همان روم را پیدا می‌کند.
2. باز بودن نشست را بررسی می‌کند.
3. همان شناسه کاربر را داخل کاربران نشست جست‌وجو می‌کند.
4. آماده بودن کاربر را بررسی می‌کند.

## نتیجه موفق

اگر کاربر داخل همان نشست باشد، این اطلاعات برگردانده می‌شوند:

- شناسه کاربر
- شناسه روم
- شناسه نشست
- شناسه سرور اختصاصی
- شناسه اتصال کاربر
- شناسه بازیکن

## نتیجه ناموفق

صوت تأیید نمی‌شود اگر:

- نشست روم وجود نداشته باشد.
- نشست بسته شده باشد.
- شناسه کاربر داخل نشست نباشد.
- کاربر هنوز آماده نشده باشد.

## منبع شناسه کاربر

برای تطبیق حضور کاربر، فقط اطلاعات همان نشست سرور اختصاصی استفاده می‌شود.

دیتابیس، اطلاعات مالکیت آواتار یا محل دیگری بررسی نمی‌شود.

## توضیح این فایل

این فایل روش ساده بررسی حضور واقعی فرستنده صوت در سرور اختصاصی همان روم را ثبت می‌کند.
