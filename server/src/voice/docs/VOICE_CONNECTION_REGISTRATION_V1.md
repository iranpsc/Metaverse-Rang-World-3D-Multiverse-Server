# ثبت اتصال صوتی

## ورودی

سرویس ثبت، نتیجه بررسی توکن، روم و سرور اختصاصی را دریافت می‌کند.

## ثبت

اتصال با این اطلاعات ثبت می‌شود:

- شناسه اتصال سرور اختصاصی
- شناسه واقعی کاربر
- شناسه آواتار
- شناسه روم
- نوع پلتفرم
- شناسه نمونه کلاینت
- نام راه انتقال
- شناسه راه انتقال

## فعال‌سازی

اتصال پس از ثبت از وضعیت احراز‌شده وارد وضعیت فعال می‌شود.

## جلوگیری از تکرار

ثبت این موارد تکراری مجاز نیست:

- شناسه اتصال یکسان
- شناسه نمونه کلاینت یکسان
- کاربر و آواتار یکسان

اگر درخواست کاملاً با اتصال فعال قبلی یکسان باشد، اتصال قبلی بازگردانده می‌شود.

## توضیح این فایل

این فایل قانون ثبت و فعال‌سازی اتصال صوتی و جلوگیری از اتصال تکراری را مشخص می‌کند.
