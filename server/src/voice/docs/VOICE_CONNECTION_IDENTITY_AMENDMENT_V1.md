# منبع شناسه اتصال صوتی

## شناسه کاربر

شناسه کاربر از اطلاعات بازیکن داخل نشست سرور اختصاصی گرفته می‌شود.

## شناسه اتصال

شناسه اتصال صوتی نیز از `connectionId` همان بازیکن داخل سرور اختصاصی گرفته می‌شود.

سرور صوتی شناسه تصادفی تازه‌ای برای همان بازیکن نمی‌سازد.

## قالب شناسه

شناسه اتصال سرور اختصاصی دارای سی و دو نویسه شانزده‌شانزدهی است.

برای هماهنگی با قالب شانزده‌بایتی پیام‌های فعلی، فقط خط تیره به آن اضافه می‌شود.

اضافه شدن خط تیره مقدار شناسه را تغییر نمی‌دهد.

## نمونه

شناسه سرور اختصاصی:

`65adc593c1b946778c79a0b1f16393ab`

شناسه استفاده‌شده در اتصال صوتی:

`65adc593-c1b9-4677-8c79-a0b1f16393ab`

هر دو نشان‌دهنده همان شانزده بایت هستند.

## بازیابی اتصال

بعد از بازیابی اتصال سرور اختصاصی، شناسه جدید همان اتصال باید دوباره از نشست سرور اختصاصی خوانده و بررسی شود.

## توضیح این فایل

این فایل مشخص می‌کند که شناسه اتصال صوتی همان شناسه اتصال بازیکن در سرور اختصاصی است و شناسه تصادفی جداگانه ساخته نمی‌شود.
