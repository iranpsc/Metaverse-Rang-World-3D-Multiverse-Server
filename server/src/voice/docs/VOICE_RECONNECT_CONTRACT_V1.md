# قرارداد بازیابی اتصال صوتی نسخه ۱

## زمان‌بندی

- نخستین تلاش بازیابی بدون تأخیر انجام می‌شود.
- کلاینت حداکثر ۱۸۰ ثانیه برای بازیابی خودکار فرصت دارد.
- سرور اتصال و نشست‌های قابل بازیابی را حداکثر ۲۱۰ ثانیه نگه می‌دارد.

## وضعیت نشست‌ها هنگام قطع موقت

هنگام قطع موقت اتصال صوتی:

- عضویت‌های قابل بازیابی به حالت تعلیق می‌روند.
- صدایی برای اتصال معلق ارسال نمی‌شود.
- همان شناسه اتصال صوتی برای ادامه موفق حفظ می‌شود.
- پس از پایان ۲۱۰ ثانیه، اتصال و نشست‌های باقی‌مانده پاک می‌شوند.

## بررسی‌های لازم هنگام بازیابی

سرور پیش از ادامه اتصال این موارد را دوباره بررسی می‌کند:

1. معتبر بودن توکن دسترسی
2. وجود شناسه کاربر در توکن تأییدشده
3. آماده بودن اتصال ریل‌تایم
4. عضویت همان کاربر در روم
5. مالکیت آواتار توسط همان کاربر
6. احراز بودن اتصال سرور اختصاصی
7. مجاز بودن دسترسی صوتی
8. معتبر بودن فاصله قطعی آواتارها

شناسه کاربر ارسالی از کلاینت مبنای بازیابی قرار نمی‌گیرد.

## نتیجه بازیابی

نتیجه موفق شامل این موارد است:

- شناسه اتصال صوتی
- شماره‌ای که دریافت صدا باید از آن ادامه پیدا کند
- زمان سرور
- تعداد نشست‌های نگهداری‌شده
- پیام نتیجه

## پاک‌سازی

- خروج از محدوده فقط همان نشست فاصله‌ای را می‌بندد.
- قطع موقت صوت، ارسال صدا را معلق می‌کند.
- خروج از روم، حذف آواتار، قطع سرور اختصاصی، پایان مهلت بازیابی یا لغو دسترسی، تمام نشست‌ها و اتصال صوتی را پاک می‌کند.

## توضیح این فایل

این فایل قوانین زمانی، امنیتی و پاک‌سازی مربوط به بازیابی اتصال صوتی را به‌صورت مکتوب ثبت می‌کند.
